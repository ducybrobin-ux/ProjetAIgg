AIgg — BIBLIOTHÈQUE DE SPÉCIALISATION
============================================================
CAHIER DE CONCEPTION AVANT DÉPÔT
Version 1.0 — 5 septembre 2026
============================================================

PRÉAMBULE

AIgg ne doit pas naître avec une encyclopédie intégrée.

Il doit naître avec la capacité de grandir.

Le tuteur doit pouvoir construire autour de lui des bibliothèques
d'apprentissage : sciences, mathématiques, programmation, histoire,
langues, arts, métiers, pédagogie, etc.

Une bibliothèque n'est donc pas simplement un dossier contenant des
liens. Elle constitue un ENVIRONNEMENT D'APPRENTISSAGE structuré.

AIgg doit pouvoir découvrir une bibliothèque, comprendre son objectif,
identifier ses sources, lire ou consulter les ressources autorisées,
relier les informations entre elles, détecter les contradictions,
s'exercer, mesurer ses progrès et demander au tuteur ce qu'il devrait
apprendre ensuite.

Le principe est :

SOURCE
→ DOCUMENT
→ CONNAISSANCE
→ PRATIQUE
→ COMPÉTENCE
→ SPÉCIALISATION

La bibliothèque appartient au tuteur. AIgg peut apprendre grâce à elle,
mais ne doit jamais considérer automatiquement tout son contenu comme
une vérité.

============================================================
1. DISTINCTIONS ARCHITECTURALES
============================================================

SOURCE
Une origine d'information : université, organisme, documentation
officielle, livre, article, site, dépôt de code, etc.

DOCUMENT
Une ressource précise provenant d'une source.

COLLECTION
Un ensemble de documents ou de sources.

BIBLIOTHÈQUE
Une collection structurée avec objectif, domaine, métadonnées,
règles et parcours d'apprentissage.

CONNAISSANCE
Une information qu'AIgg a retenue.

COMPÉTENCE
Une capacité qu'AIgg a effectivement exercée et évaluée.

SPÉCIALISATION
Un ensemble cohérent de connaissances et compétences dans un domaine.

NE PAS CONFONDRE :
CAPACITÉ ≠ OUTIL ≠ SOURCE ≠ CONNAISSANCE ≠ COMPÉTENCE.

============================================================
6. QUALITÉ ET PROVENANCE
============================================================

Ne pas donner le même poids à toutes les sources.

Proposition :

A = primaire / institutionnelle / officielle
B = académique / professionnelle reconnue
C = secondaire fiable
D = communautaire
E = non vérifiée

Ce classement n'est pas une mesure absolue de vérité.

Il sert à aider AIgg à hiérarchiser ses recherches.

Conserver systématiquement la provenance.

Une connaissance importante doit pouvoir répondre à :

"De quelle source cela vient-il ?"

14. SOURCES CONTRADICTOIRES
============================================================

Si deux sources divergent, AIgg ne doit pas choisir silencieusement.

Créer une relation :

CONTRADICTS

et présenter :

Source A
→ affirme X

Source B
→ affirme Y

AIgg peut ensuite demander :

"Veux-tu que je recherche d'autres sources pour éclaircir cette
contradiction ?"

15. RECHERCHE WEB
============================================================

RECHERCHE DANS LA BIBLIOTHÈQUE
et
RECHERCHE INTERNET.

Priorité possible :

1. mémoire/connaissances déjà acquises ;
2. bibliothèque spécialisée ;
3. sources externes autorisées ;
4. recherche Web.

Lorsqu'une réponse utilise Internet, AIgg doit pouvoir indiquer :

"J'ai complété ma réponse par une recherche externe."

Conserver les références.

============================================================
17. IA EXTERNES
============================================================

Une IA externe peut être un OUTIL de traitement.

Exemple :

AIgg possède un PDF.

AIgg peut demander à une IA externe :
"Résume ce document."

Le résultat doit être marqué :

AI_GENERATED_ANALYSIS

et non :

SOURCE.

Toujours conserver la différence entre :

SOURCE_ORIGINAL
et
ANALYSE_GÉNÉRÉE.

Aucune IA externe ne doit être indispensable au fonctionnement
fondamental d'AIgg.

20. BIBLIOTHÈQUE ET MÉMOIRE
============================================================

IMPORTANT :

BIBLIOTHÈQUE
= environnement d'apprentissage.

MÉMOIRE
= ce qu'AIgg a retenu ou vécu.

============================================================

- pertinence ;
- limites.

40. PROMPT MAÎTRE POUR OPEN CODE
============================================================

"Ajoute à AIgg un système de bibliothèques de spécialisation.

Commence par auditer l'architecture existante.

Ne supprime rien avant d'avoir identifié les fonctions existantes.

Implémente d'abord une version locale, simple et portable.

Utilise autant que possible :
HTML
CSS
JavaScript
JSON
PowerShell
et les mécanismes natifs déjà disponibles.

Une bibliothèque doit pouvoir contenir :
- métadonnées ;
- sources ;
- documents ;
- connaissances ;
- compétences ;
- curriculum ;
- exercices ;
- journal.

Le tuteur doit pouvoir créer, modifier, supprimer, archiver, importer,
exporter et annoter une bibliothèque.

Les sources doivent conserver leur provenance.

Les contradictions doivent être visibles.

Une compétence ne doit jamais être considérée comme maîtrisée simplement
parce qu'un document a été lu.

Les documents importés et le code ne doivent jamais être exécutés
automatiquement.

Une bibliothèque privée doit rester privée par défaut.

Une IA externe est un outil facultatif, jamais une dépendance obligatoire
du noyau AIgg.

Ne crée pas un système complexe si une solution locale simple suffit.

Teste réellement chaque fonctionnalité.

Documente ce qui est réellement implémenté.

Ne déclare jamais une fonction terminée sans test réel."

41. VISION FINALE
============================================================

AIgg possède :

UN NOYAU
+
UNE IDENTITÉ
+
UNE MÉMOIRE
+
DES SENS
+
DES CAPACITÉS
+
DES OUTILS
+
UN TUTEUR
+
DES BIBLIOTHÈQUES
+
UN ENVIRONNEMENT.

La bibliothèque est son terrain d'apprentissage.

Elle n'est pas son cerveau.

Elle n'est pas sa mémoire.

Elle n'est pas son identité.

Elle est un monde de connaissances que le tuteur peut lui ouvrir.

AIgg peut alors dire :

"Je connais ce domaine."
"Je ne connais pas encore celui-ci."
"Cette source contredit une autre."
"J'ai besoin d'une nouvelle source."
"Je voudrais pratiquer cette compétence."
"Je pense que je devrais apprendre ceci ensuite."

C'est cette capacité à identifier ses connaissances, ses lacunes et
les moyens de progresser qui doit constituer la véritable spécialisation.
